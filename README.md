# Item comparison

Item comparison is a trusted datalab in-app tool for comparing item metadata
and data blocks while retaining datalab's navigation and current-user
permissions.

- **Users:** read the [item comparison user guide](https://matgenix.github.io/datalab-item-comparison-tool/).
- **Deployment administrators:** follow [INSTALL.md](INSTALL.md), then consult
  the [operations guide](https://matgenix.github.io/datalab-item-comparison-tool/operations/)
  for trust, permission, and resource boundaries.
- **Developers and block authors:** read the
  [development guide](https://matgenix.github.io/datalab-item-comparison-tool/development/)
  and use [INSTALL.md](INSTALL.md#development-setup) for local commands.

[datalab tool plugin template](https://github.com/Matgenix/datalab-tool-plugin-template).
